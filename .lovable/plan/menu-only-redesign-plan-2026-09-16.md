# Menu-only redesign plan

## What will change
- Restyle only the `/menu` page to mirror the reference’s compact premium catering layout.
- Keep the background warm cream, with dark chocolate text and subtle beige/gold accents.
- Preserve every existing dish, image, category filter, search control, and interaction.
- Change the menu-page brand label from “Seezen Caterers” to “HUZEE CATERERS”.
- Add the requested Ice Cream dishes to the existing Ice-Cream category without removing existing entries or creating a duplicate category.

## Layout
- Mobile: two equal columns of compact dish rows/cards, each retaining its thumbnail and name.
- Desktop/laptop: a balanced responsive grid with more columns and restrained spacing.
- Keep rounded category filters, but make them smaller and closer to the reference.
- Reduce oversized category containers and typography while preserving clear hierarchy.

## Technical details
- Limit presentation changes to the menu page and shared color tokens only if required.
- Extend the existing menu data and image-matching rules for the added ice cream names.
- Validate search, filters, mobile two-column layout, desktop layout, and all page metadata after implementation.
